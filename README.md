# StockFlow

Sistema web de gerenciamento de estoque desenvolvido como projeto de portfólio para praticar desenvolvimento frontend e backend.

# Funcionalidades

- Produtos: cadastro, consulta, atualização e exclusão.
- Categorias: gerenciamento das categorias de produtos.
- Vendas: registro e consulta de vendas, com atualização automática do estoque.
- Controle de estoque: validação da quantidade disponível e identificação de produtos com estoque baixo.
- Autenticação: cadastro e login de usuários com proteção das rotas.

# Tecnologias utilizadas

# Frontend
- React
- JavaScript
- Vite
- CSS
- React Router

# Backend
- Node.js
- Express
- Prisma ORM
- PostgreSQL
- JSON Web Tokens (JWT)
- bcrypt

# Estrutura do projeto

- backend/: API, rotas, validações, autenticação e acesso ao banco de dados.
- frontend/: interface web, páginas e componentes React.

# Objetivo

O StockFlow foi desenvolvido com o objetivo de consolidar conhecimentos em desenvolvimento web, operações CRUD, integração entre frontend e backend, autenticação e gerenciamento de estoque.
